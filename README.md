# Mustapha Sobhy | Portfolio

A personal portfolio website built with HTML, CSS, and JavaScript to showcase my work, skills, and contact information.

## Overview

This project presents my developer profile in a clean, responsive, and accessible single-page portfolio. It highlights selected projects, demonstrates web development skills, and includes a contact section with client-side validation.

## Features

- Responsive single-page portfolio layout
- Accessible navigation and skip link support
- Project cards with category filters
- Click-to-expand image lightbox for project screenshots
- Mobile-friendly menu interaction
- Contact form with validation feedback
- Clean, modern design

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Accessibility best practices
